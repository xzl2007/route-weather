# 路线天气体检

> 出发前输入一条路线，得到一份一眼能看懂的「天气体检报告」：
> 明天这条路适不适合走、几点出发最稳、每个点逐小时什么天气、哪个点最难受。

**不是导航，不是预警，是「行程的天气体检」。**

![界面总览](shots/overview.png)

---

## 它解决什么问题

天气 App 告诉你「雅安明天有雨」，导航告诉你「这条路怎么走、要多久」。
但没有人回答你真正想问的那句：

> 我这条 **雅安 → 天全 → 泸定** 的线，明天 6 点到 9 点走最稳，
> 下午 1 点后经过泸定会很难受。

路线天气体检做的就是这件事：**把气象预报翻译成一条路线的行程建议。**

| 产品 | 单位 | 告诉你什么 |
|---|---|---|
| 天气 App | 一个城市 | 降水、气温、未来 7 天 |
| 地图导航 | 一条道路 | 怎么走、多久到、堵不堵 |
| **路线天气体检** | **一条行程的点位** | **这条路明天适不适合走、几点走、哪个点最难受** |

---

## 怎么用

1. **输入路线** —— 起点 + 途经点 + 终点，选出行日期和出行方式（自驾 / 徒步 / 骑行）。
   可以直接在地图上点选，也可以搜全国任意地名，或用内置点位库快速挑。
   加好点位后**拖动左侧「⋮⋮」把手可以调整顺序**（起点/终点会跟着变）。
2. **开始体检** —— 几秒后出报告。
3. **看报告** —— 结论卡、逐点位天气、最佳出发时间、最差点位、出行准备建议。

地图支持**双指捏合 / 滚轮缩放 / 双击放大**，桌面端左上角还有 **+ − 缩放按钮**。

**无需注册、无需登录、无需安装。** 行程只存在你自己的设备上。

## 两种模式

| | 规划模式（行程诊断） | 导航模式（智能排程） |
|---|---|---|
| 你输入 | 点位 **+ 每个点的到达时间**（你自己排） | 只给起点和终点（系统排时间） |
| 它做什么 | **核对**你的计划：哪段不合理、为什么、怎么改 | **生成**方案：算路径、算到达时刻、推荐几点出发 |
| 天气取哪一刻 | 每个点取**你安排的到达时刻** | 每个点取**系统预计到达那一刻** |
| 输出 | 诊断清单（⛔ 需调整 / ⚠️ 建议微调 / ✅ 合理）+ 修改建议 | 最优出发时刻 + 逐段风险 |
| 地图显示 | 点位连线 | 真实道路路径 |
| 适合 | 心里已有行程表，想让人挑毛病 | 只想问「从 A 到 B 这一路行不行、几点走」 |

**规划模式的五条诊断规则**：R1 单点天气不适合 / R2 高海拔午后 / R3 时间安排过紧 / R4 天黑前未通过 / R5 连续点位都在降雨。
每条都输出「证据 + 影响 + 建议」，不出现无法解释的结论。

### 本次新增（2026-10-18）

- **新建页地图支持全屏**：地图右上角「⛶ 全屏」，全屏下可直接点图选点，ESC 或「✕ 退出」返回。
- **新建页可切换底图**：右上角按钮在「普通（矢量路网）」与「地形（晕渲）」两种之间切换，切换后地图与点位一起重建。
- **沿途自动采样**：在关键点位之间按里程采样（约每 8 km，总数上限 20 个），路线分取**所有采样点**的最低分，不再只看输入的几个点。
- **地形剖面**：由采样点高程计算**累计爬升 / 累计下降 / 最高海拔 / 地形平均坡度**，并新增「连续爬升」「长下坡」「高海拔」三条提醒。
- **逐小时天气常显**：每张点位卡片默认展示**行程日 24 小时**的天气条（时刻 / 天气图标 / 气温 / 降水概率 / 评分），到达时刻高亮；点开可看含风速的明细表。

**导航模式为什么有意义**：成都到稻城约 **7.9 小时**。
如果第 8 个采样点也用出发时刻的天气，等于用早上的天气去判断下午 4 点折多山的路况 ——
在山区，这是错的。所以每个采样点都按「预计到达那一刻」单独取天气。

## 报告怎么看

### 评分规则（可解释、可复现）

单点评分从 100 分起扣，扣分项包括：降水概率、降水量、风速、气温偏离舒适区、
结冰风险、天气现象、高海拔。

| 分数 | 等级 | 含义 |
|---|---|---|
| ≥ 80 | 🟢 适宜 | 适合出行 |
| 60–79 | 🟡 一般 | 可以出行，注意天气变化 |
| 40–59 | 🟠 谨慎 | 谨慎出行 |
| < 40 | 🔴 不建议 | 不建议出行 |

**路线分 = 各点位中的最低分。**
一个人可以在 85 分的路段上走，但整条行程的安全性由**最差的那一段**决定。
报告里同时给出平均分，避免只看到最坏情况。

**不可解释即不输出** —— 每个分数都会列出主要扣分项；列不出原因，就不显示分数。

### 最佳出发时间

有满足条件的连续时段时，给出其中最优的一段（不超过 6 小时）。

没有完全适宜的时段时，**不会只写「无」**，而是给出
「最接近的时段 + 全线最低分 + 瓶颈点位」，让你知道差在哪、可以怎么调整。

### 高海拔提示

海拔超过 3000 米的点位会额外扣分并单独标注 —— 这是通用天气 App 不会做的事，
也是本作品面向**山区路线**的差异化点。

## 数据来源与合规

| 用途 | 来源 | 授权 |
|---|---|---|
| 逐小时气象预报、海拔 | [Open-Meteo](https://open-meteo.com/) | CC BY 4.0 |
| 路径规划（导航模式） | [OSRM](https://project-osrm.org/) | 路网数据 © OpenStreetMap contributors |
| 地图底图 | [天地图](https://www.tianditu.gov.cn/) | 国家地理信息公共服务平台 |

**署名**：报告页底部固定显示数据来源、更新时间，以及

> 天气数据来源：Open-Meteo.com（CC BY 4.0）｜适宜度评分与行程结论由本作品计算生成

这样就明确区分了「数据是别人的、评分是我们的」。

**隐私**

- 不采集姓名、手机号等身份信息，无需登录
- 位置仅用于气象查询，不长期保存精确坐标
- 行程数据**只存在你的设备上**，不上传服务器

## 已知限制

1. **仅评估你输入的点位**，点位之间的路段不在评估范围内
2. **到达时刻按平均速度估算**，未考虑堵车、休息、封路等实际情况
3. **路网限速估算偏乐观**，山区实际车速通常更慢，建议按抵达时刻预留 20–30% 余量
4. **山区局地精度有限** —— 气象预报来自全球模型，川西高山峡谷地形复杂
5. **地名搜索需联网** —— 支持全国地名（天地图地理编码），断网时只能用内置的 23 个川西/川北点位
6. **不发布预警、不提供实时路况、不做路径规划**
7. 分享卡片、订阅提醒、长图导出、多行程对比等功能尚未实现

> **这是参考性评估，不构成安全保证，不替代官方预警信息与现场判断。**
